Response Integrity-OS BATTLE TEST: SESSION CONTEXT AND DRILL FLOW

SECTION 1: OPERATING MAP

Q1
What is the difference between session context and drill type?

Expected Answer
Session context explains why the session exists. Drill type is the procedure run inside that context to serve its purpose.

Fail Answer
They are two names for the same thing
The phase decides the session context
The tutor chooses whichever sounds suitable

Q2
What are the three live session contexts?

Expected Answer
Intro, Active Training, and Tutor Handover Verification.

Fail Answer
Clarity, execution, and pressure
Diagnosis, training, and verification
Teaching, practice, and testing

Q3
What are the three drill types?

Expected Answer
Diagnosis, Training, and Verification.

Fail Answer
Intro, active, and handover
Clarity, discomfort, and time
Easy, medium, and hard

Q4
Which drill type serves an Intro session, and why?

Expected Answer
Diagnosis, because Intro exists to place the topic-entry state rather than run normal training.

Fail Answer
Training, to start progress immediately
Verification, because the parent supplied a recommendation
Any drill the tutor prefers

SECTION 2: ACTIVE TRAINING AND HANDOVER

Q5
What is the default drill type in Active Training?

Expected Answer
The system-selected Training drill for the topic's current phase and state.

Fail Answer
Diagnosis every session
The tutor's favourite drill
Whichever phase looked weak last week

Q6
When can Diagnosis appear inside an Active Training session?

Expected Answer
When a newly activated topic needs entry placement. That topic is diagnosed without turning the entire session into a new Intro.

Fail Answer
Whenever an existing topic has one weak rep
At the start of every session
When the tutor wants to recheck everything

Q7
Which drill type serves Tutor Handover Verification, and why?

Expected Answer
Verification, because the student already has inherited topic-state and the new tutor must confirm continuity rather than restart placement or begin normal training immediately.

Fail Answer
Diagnosis because the tutor is new
Training because the student is already active
The tutor decides after meeting the student

Q8
Why does the current transformation phase not replace session context?

Expected Answer
Phase is the capability being conditioned inside a topic. Session context is why the session exists. Any current phase can be trained or verified within the appropriate context.

Fail Answer
Every Clarity phase is an Intro
Every advanced phase is Active Training
Phase and context always match one-to-one

Q9
May the Specialist replace the system-selected drill because another activity feels more suitable?

Expected Answer
No. The Specialist follows the assigned topic-state and drill. Any authorised change must come from captured evidence and the system flow, not tutor instinct.

Fail Answer
Yes, good tutors adapt freely
Yes, if the student prefers it
The system recommendation is optional

Q10
How does preparation protect session flow?

Expected Answer
It gives the Specialist the exact problems, order, constraints, and adjacent coverage required for the assigned context so the live session does not become improvised or drift into another drill type.

Fail Answer
Preparation is only choosing a topic
Improvisation is more responsive
The platform supplies everything during the session

SECTION 3: PRESSURE SCENARIOS

Scenario 1
During Active Training, an existing Structured Execution topic has one weak rep. The Specialist abandons the assigned training drill and starts a fresh diagnosis. What is wrong?

Expected Answer
One weak rep should be logged inside the assigned training flow. The Specialist cannot re-place an existing topic by instinct; the system uses the evidence to determine the next action.

Fail Answer
Nothing; weakness always requires diagnosis
The tutor should also restart Clarity
Diagnosis is safer than following the drill

Scenario 2
A new fractions topic becomes active midway through a normal training session. What happens?

Expected Answer
Run the authorised Diagnosis flow for that new topic to establish entry placement, while the overall session remains an Active Training context.

Fail Answer
Train it from Clarity automatically
Wait until a new Intro session
Use the phase of the student's other topics

Scenario 3
A replacement tutor treats Handover as a fresh Intro and discards the inherited state. What boundary was broken?

Expected Answer
The tutor confused continuity verification with new placement, erased valid history, and bypassed the Handover context.

Fail Answer
Nothing; every new tutor should start over
Fresh diagnosis is always more accurate
The inherited state is only a suggestion

Scenario 4
An Intro diagnosis locks the entry point with twenty minutes remaining. Should the Specialist fill the time with normal training?

Expected Answer
No. Intro ends when placement is locked. Do not convert the remaining time into an unassigned training cycle.

Fail Answer
Yes, to deliver value
Yes, if the student is doing well
Keep testing higher phases instead

Fail Answer
